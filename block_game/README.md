# Block Drop (рабочее название)

Мобильная игра с падающими блоками для Android на Godot 4.3. Название и оформление свои, не «Тетрис».

## Как запустить
1. Установить Godot 4.3: https://godotengine.org/download
2. В Godot: Import → выбрать `block_game/project.godot` → Run (F5).
3. На компьютере: стрелки, ↑ поворот, пробел сброс, P пауза. Мышь работает как касание.

Тесты логики:
```
godot --headless --path block_game -s tests/test_logic.gd
```

## Управление на телефоне
- Кнопки внизу: влево, вправо, вниз (удерживать), сбросить, повернуть.
- Жесты на поле: тап поворачивает, проведение влево или вправо двигает, проведение вниз ускоряет, резкий свайп вниз сбрасывает.
- Пауза: кнопка справа сверху; игра сама встаёт на паузу при сворачивании и при нажатии «Назад».

## Что уже есть (версия 0.1)
- Поле 10×20, 7 фигур, «мешок» из 7 фигур без длинных повторов, следующая фигура.

- Очки, уровни (каждые 10 линий быстрее), рекорд сохраняется на устройстве.
