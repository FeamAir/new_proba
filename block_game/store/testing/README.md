# Закрытое тестирование Cascado

- **Сейчас:** Владимир собирает тестировщиков сообщением из `recruit_message.md` (RU/EN). Цель — **15–20 человек** (запас на тех, кто выйдет).
- Список тестировщиков с почтами **не хранить в GitHub** (это личные данные): держать у Владимира, шаблон колонок — `testers_list_template.csv`.
- **Правило Google** (проверить по свежей справке перед стартом): к подаче заявки ≥12 тестировщиков, каждый непрерывно в тесте последние 14 дней. Можно присоединяться постепенно; вышедший теряет только свой стаж. Счётчик — в Play Console.
- **План:** оформить «клуб тестировщиков» как группу Google — для следующих игр студии добавлять одной строкой.
- **Когда игра готова:** создать закрытый тест в Play Console → добавить группу/почты → разослать ссылку-приглашение с пошаговой инструкцией (подготовить) → постараться, чтобы все зашли в первые 2–3 дня.
- **Во время теста:** собирать отзывы (анкета — подготовить), просить тестировщиков прислать таблицу со скрытого экрана статистики (пауза → 5 нажатий по номеру версии → «Скопировать»).
- **После выхода:** проверить актуальные условия Google Play Pass и при возможности подать заявку.
