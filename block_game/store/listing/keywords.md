# Cascado: search keywords (English)

Status: DRAFT.

Google Play has no separate keyword field. It reads the title, the short description and the full description.
So keywords must be written naturally into the text. Repeating a word many times or listing keywords
is "keyword spam" and breaks Google Play rules.
Never use: Tetris, tetromino, names of other games or companies (for example other block puzzle brands).

## Main phrases (where they are in en.md)

| Keyword / phrase | Where it is used | Why |
|------------------|------------------|-----|
| block puzzle | title ("Crystal Block Puzzle") | the most common search for this genre |
| crystal / crystals | title, short, full | our unique goal; also matches "crystal puzzle", "gem puzzle" searches |
| falling-block puzzle / falling blocks | full description, first paragraph | describes the genre without brand names |
| clear lines / line clear | full description | how players describe the core action |
| cascade / cascade combo | brand name, short, full | our hook; matches "combo", "chain" searches |
| combo / combos | short, full | common search word for puzzle games |
| chain reaction | full description | natural phrase for cascades |
| levels / 50 levels / handcrafted levels | full description | level-based puzzle searches |
| stars (1 to 3 stars) | full description | level-puzzle players look for it |
| relaxing / calm / cozy | full description, short (backup) | "relaxing puzzle", "cozy game" searches |
| offline / no internet | full description | "offline games", "games without wifi" searches |
| no ads | full description | "puzzle no ads" searches (keep only while true) |
| owl / axolotl | short, full | cute-character searches, distinct from competitors |
| dress up / wardrobe / outfits | short, full | collection and customization fans |
| decorate / home / decorations | full description | home decoration fans |
| cave / gems | full description | theme searches |
| brain / puzzle game | (could add) | wide genre words |

## Secondary ideas (only if they fit naturally in a future text update)
- "brain teaser", "logic puzzle", "strategy puzzle" — only if the text stays honest (Cascado is more calm than hard).
- "block drop", "drop puzzle".
- "cute puzzle game", "cozy puzzle".

## Do not use
- Tetris / tetromino / any other game or company brand.
- "best", "top", "#1", "free" in the title; "popular", "most downloaded" anywhere.
- "multiplayer", "online", "leaderboard", "daily challenge", "events" — the game does not have them.
- "kids game", "for children" — our target rating is 13+, and a children's audience brings extra Google rules.
