# Cascado — анкета «Безопасность данных» (Data safety)

Для версии 0.2 (versionCode 2). Подготовлено 25.11.2026.
Раздел в Play Console: «Контент приложения» → «Безопасность данных»
(App content → Data safety). Справка Google: https://support.google.com/googleplay/android-developer/answer/10787469

## Что проверено

| Что | Где | Результат |
|---|---|---|
| Сохранение | `scripts/game.gd`, функции `_load()` / `_save()` | Только `user://save.cfg`: открытый уровень, звёзды, музыка вкл/выкл, звуки вкл/выкл |
| Сеть | `scripts/game.gd` | Нет HTTPRequest, HTTPClient, WebSocket, сокетов |
| Идентификаторы | `scripts/game.gd` | Нет `OS.get_unique_id()`, рекламного ID, буфера обмена |
| Сторонние SDK | `export_presets.cfg` | Нет плагинов, нет AdMob, Firebase, Play Games, Billing |
| Разрешения Android | `export_presets.cfg` | Ни одного разрешения не включено |
| Резервная копия | шаблон Godot 4.3, AndroidManifest | `allowBackup="false"`: файл не уходит в облако Google |

Правило Google: данные, которые обрабатываются **только на устройстве** и не отправляются
с него, **не считаются «собранными»** и в анкете не указываются.

**Проверить на итоговой сборке (AAB для магазина):** в манифесте не должно быть
разрешения `INTERNET`. Godot добавляет его в отладочные сборки для удалённой отладки;
в релизной сборке его быть не должно. Если оно есть — это не нарушение, но стоит
понять, откуда оно взялось.

## Ответы (текущая версия)

| Вопрос в анкете | Ответ |
|---|---|
| Собирает ли приложение или передаёт третьим лицам какие-либо из перечисленных типов данных? (Does your app collect or share any of the required user data types?) | **Нет** (No) |

После ответа «Нет» остальные вопросы (шифрование при передаче, удаление данных,
типы данных) не задаются. В магазине будет показано: «Данные не собираются» и
«Данные не передаются третьим лицам» (No data collected / No data shared).

Ссылка на политику конфиденциальности всё равно обязательна для всех приложений:
указывается в разделе «Политика конфиденциальности» (Privacy policy).

## Соседние разделы «Контента приложения» (для текущей версии)

| Раздел | Ответ |
|---|---|
| Реклама (Ads) | Приложение **не содержит** рекламы |
| Доступ к приложению (App access) | Все функции доступны **без входа** и без особых условий |
| Рекламный идентификатор (Advertising ID) | Приложение **не использует** рекламный ID |
| Целевая аудитория (Target audience) | **Нужно решение Владимира** (см. checklist.md, пункт про детей) |
| Финансовые функции, здоровье, новости, госприложение | Нет / не относится |

## Что изменится в будущих версиях (предварительно, сверить с документацией SDK)

Когда в игре появятся эти сервисы, ответ «Нет» станет **неверным**. Анкету и
политику нужно обновить **до** отправки такой версии на проверку.

| Сервис | Что, скорее всего, придётся указать |
|---|---|
| AdMob (реклама) | Идентификаторы устройства (рекламный ID), взаимодействие с приложением, диагностика, примерное местоположение (по IP); передача третьим лицам — да; цель — реклама, аналитика |
| Покупки через Google Play Billing | История покупок |
| Google Play Games (рекорды) | Идентификаторы пользователя (игровой профиль), игровой прогресс/рекорды |
| Firebase Analytics | Идентификаторы устройства, взаимодействие с приложением, диагностика |

Точный список данных у каждого SDK берётся из его официальной страницы «Data safety»
(у Google для AdMob и Firebase такие страницы есть). Если целевая аудитория будет
включать детей до 13 лет, требования к рекламе и аналитике станут намного строже.
