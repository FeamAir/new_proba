# Герои — исходники картинок (этап 1)

Полноразмерные PNG с прозрачностью, обрезанные по содержимому. Godot их не импортирует (`art_src/.gdignore`).
Уменьшенные копии для игры (высота 512 px, WebP 85) — `assets/heroes_art/<герой>/`, те же имена.

Имя файла: `<облик>_<окрас>_<поза>.png`
- облик: `boy`, `girl` (у Мастера Уха — `master`);
- окрас: `base` или ключ палитры из `scripts/hero.gd` (= поле `draw` вещи окраса в `meta.gd`, если оно есть):
  - owl: `skin_constellation` (ow_skin_starry), `ow_skin_snowy`;
  - axolotl: `skin_pearl` (ax_skin_pearl), `skin_midnight` (ax_skin_abyss);
  - puppy: `skin_moon` (корги), `skin_gold` (далматинец), `pu_skin_cotton` (сахарная вата);
  - kitten: `skin_mint` (полосатый), `skin_moon` (сиамский);
- поза: `idle`, `happy` (прыжок, лапы в воздухе), `wow`, `worried`, `sad`; у Мастера Уха — `talk`, `happy`, `forge`.

Признаки облика: совёнок — мальчик с завитком-пёрышком и бровками, девочка с розовым цветком на ушке;
аксолотль — мальчик с бровками, девочка со звёздочкой-заколкой; щенок — мальчик с хохолком,
девочка с бантиком на левом ушке; котик — мальчик с хохолком и бровками-точками, девочка с цветочком.
У девочек — реснички.

`anchors.json` — точки привязки вещей (доли ширины/высоты картинки): head, eyes, neck, back, ground.
`cost_log.csv` — журнал платных вызовов fal.ai.

## Источник и права
Сторонних ассетов нет. Картинки нарисованы нейросетью по заказу проекта через fal.ai:
`fal-ai/nano-banana/edit` (Google Gemini 2.5 Flash Image), фон убран `fal-ai/birefnet`.
Образцы — собственные герои игры (снимки из `scripts/hero.gd`) и утверждённый владельцем пробный котик.
По условиям fal.ai и Google права на результат у заказчика, коммерческое использование разрешено.
