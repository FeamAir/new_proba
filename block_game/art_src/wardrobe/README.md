# Гардероб — исходники картинок (этап 2 перерисовки)

Полноразмерные PNG с прозрачностью, обрезанные по содержимому: `art_src/wardrobe/<герой>/<имя>.png`.
Godot их не импортирует (`art_src/.gdignore`). Файлы для игры — `assets/wardrobe_art/` (собирает `export.py`).

## Что здесь
- **Вещи head / eyes / neck / back и спутники** — по картинке на вещь, вид спереди, стиль героев этапа 1.
  Имя файла = id вещи из `scripts/meta.gd`; у вещей из нескольких частей — свои имена слоёв:
  - `ax_shell_pack` (ракушка позади) + `ax_shell_strap` (жемчужная лямка спереди, дважды — вторая отражена);
  - `ax_wave_cape` (плащ позади) + `ax_wave_clasp` (застёжка-ракушка на шее);
  - `ax_gill_pearls` → `ax_gill_pearl` (одна жемчужина, ставится 6 раз на кончики жабр);
  - `pu_jetpack` (ракеты позади) + `pu_jetpack_straps` (лямки спереди);
  - `ki_trench` (плащ позади) + `ki_trench_collar` (лацканы спереди); `ki_ball_cloak` + `ki_ball_clasp`;
  - `ki_sweater` — спереди на туловище (поверх лапок).
- **Супер-эксклюзивы** (slot aura с `covers`) — носимые части отдельно, сияние — частицы кода:
  - `ow_stargazer` → `ow_stargazer_hat` (колпак) + `ow_stargazer_mantle` (мантия позади);
  - `ax_abyssal` → `ax_abyssal_crown` (жемчужная корона);
  - `pu_hero` → `pu_hero_mask` + `pu_hero_medal` + `pu_hero_cape` (плащ позади);
  - `ki_starry` → `ki_starry_tiara` (девочка) / `ki_starry_crown` (мальчик).
  Светящиеся глаза, веснушки, жабры, звёздный хвост — не картинки, остаются эффектами кода.
- **Сияния (12 шт.)** — `<id>.png` это только ИКОНКА для карточки; `<id>_glow.png` — мягкий ореол позади героя
  (рисуется программой в `export.py`, не нейросетью). Сами эффекты (пузыри, звёзды, молнии, салют) — частицы кода.
- **Окрасы** не рисовались заново: иконка окраса — голова героя этого окраса из этапа 1 (`export.py`).

## Файлы
- `fit.json` — посадка каждого слоя на героя (точка крепления на картинке, ширина, сдвиг, поправки поз). Описание полей — в самом файле (`_about`) и в начале `compose.py`.
- `compose.py` — сборка наряда: герой + поза + список вещей → картинка (PIL). Образец логики для Godot.
  `python3 compose.py owl idle ow_mortarboard ow_halfglasses ow_book --out=/tmp/owl.png`
- `export.py` — сборка игровых WebP: слои до 384 px, иконки 160×160 (`icons/<id>.webp`, у окрасов ещё `<id>_girl.webp`).
- `gen.py` — как картинки заказывались у нейросети (тексты заданий). Повторять не нужно.
- `cost_log.csv` — журнал платных вызовов fal.ai этапа 2.

Доработки программой после генерации: у `pu_flower_scarf`, `ki_bell_bow` вырезана задняя дуга кольца
(её закрывает шея), у `pu_bolt_band` — нижняя дуга; `ax_shell_strap` вырезан из пары лямок.

## Источник и права
Сторонних ассетов нет. Картинки нарисованы нейросетью по заказу проекта через fal.ai:
`fal-ai/nano-banana/edit` (Google Gemini 2.5 Flash Image), фон убран `fal-ai/birefnet`.
Образцы — собственные рисунки вещей игры (снимки из `scripts/wardrobe_*.gd`, `scripts/hero_sets.gd`) и герои этапа 1.
Ореолы сияний нарисованы программой. Запись — в `assets/CREDITS.md`.
